# RedPulse AI v3.8.0 — Platform Consolidation

v3.8.0 consolidates the planned production-readiness work through the former v4.0 target into one release line. It extends the existing RedPulse architecture with explicit failure engineering, event contracts, fleet analytics primitives, MLOps lifecycle controls, advanced failure estimation, human-approved agentic maintenance, enterprise integration contracts, tenant authorization, SRE/SLO primitives, benchmarking, and a release-evidence gate.

## Included capability domains

- Runtime failure engineering: retry classification, exponential backoff, retry budgets, dead-letter records.
- Durable-runtime continuation: v3.7.1 PostgreSQL leases, heartbeat, stale-worker takeover, ownership fencing.
- Transactional-outbox contract and idempotent event-consumer contract.
- Event-driven industrial platform contracts compatible with Kafka adapters.
- Fleet similarity and cross-machine behavioral comparison primitives.
- Model lifecycle registry/promotion controls for champion/challenger workflows.
- Advanced failure-risk, horizon, confidence, and evidence estimation.
- Evidence-grounded maintenance proposals with mandatory human approval boundary.
- Vendor-independent Integration Gateway contracts for n8n, Power Automate, and webhooks.
- Tenant-aware RBAC authorization primitive.
- Runtime recovery metrics and SLO evaluation.
- Reproducible benchmark harness.
- Explicit v3.8 release evidence gate.

## Existing platform foundations reused

The release intentionally reuses existing RedPulse Kafka/streaming, Spark analytics, Airflow orchestration, Kubernetes/Helm-oriented deployment, Databricks/lakehouse, security, observability, MLOps, integrations, predictive intelligence, and v3.7.1 durable replay foundations rather than creating parallel stacks.

## Engineering boundaries

This repository remains an experimental engineering/research platform. v3.8.0 does not by itself prove a live industrial deployment, safety certification, arbitrary exactly-once external side effects, industrial-scale throughput, or autonomous physical maintenance. Environment-dependent validation must be recorded as evidence before those claims are made.
