# v3.10.0 — Event-Driven Industrial Platform

## Goal

Introduce Kafka where streaming scale and durable industrial event flow justify it.

## Target Flow

Machine / Simulator
→ Kafka
→ Telemetry Ingestion
→ Behavioral Intelligence
→ Anomaly / Drift Detection
→ Failure Intelligence
→ Maintenance Events

## Scope

- Kafka producers and consumers
- Telemetry topics
- Maintenance-event topics
- Consumer groups
- Partitioning strategy
- Event keys
- Schema/versioning strategy
- Idempotent consumption
- Consumer retry strategy
- Dead-letter topics
- Replay
- Backpressure handling
- Event observability
- Ordering guarantees documented by key/partition

## Exit Criteria

- End-to-end event flow demonstrated
- Reproducible replay test
- Duplicate-event handling tested
- Consumer failure recovery tested
- Topic and schema conventions documented
