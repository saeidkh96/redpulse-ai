# v3.15.0 — Enterprise Automation & Integration

## Goal

Connect RedPulse intelligence to real enterprise workflow systems through a vendor-independent Integration Gateway.

## Integration Gateway

RedPulse
→ Integration Gateway
→ n8n
→ Microsoft Power Automate
→ Generic Webhooks
→ Teams / Outlook
→ Slack
→ Jira
→ Future adapters

## Scope

- Integration Gateway interface
- Adapter contracts
- n8n adapter
- Power Automate adapter
- Generic webhook adapter
- Retry/idempotency policy for outbound workflow events
- Authentication/secrets boundaries
- Approval workflow support
- Teams notifications
- Outlook/email workflows
- Jira ticket workflows
- Slack notifications
- SharePoint/Planner-compatible workflow hooks where justified
- Power BI-related workflow hooks where justified

## Design Rule

RedPulse core intelligence must remain independent of any automation vendor.

## Exit Criteria

- At least one end-to-end workflow through each primary adapter class
- Integration retries tested
- Duplicate outbound event behavior documented
- Secrets are not embedded in source
