# v3.12.0 — Production MLOps

## Goal

Create a traceable lifecycle from data and training through deployment, monitoring, comparison, and retraining.

## Target Lifecycle

Data
→ Feature Engineering
→ Training
→ Evaluation
→ Model Registry
→ Deployment
→ Monitoring
→ Retraining

## Scope

- Experiment tracking
- Model registry
- Model versioning
- Dataset lineage/version references
- Evaluation reports
- Promotion criteria
- Champion/challenger workflow
- A/B testing foundations
- Model rollback
- Drift monitoring
- Prediction-quality monitoring where labels exist
- Automated retraining workflow
- Airflow orchestration for scheduled pipelines
- Model deployment metadata

## Exit Criteria

- A model can move through a documented lifecycle
- Registry state is traceable
- Retraining is reproducible
- Rollback path tested
- Monitoring separates data drift from model-quality degradation
