# v3.16.0 — Security & Enterprise Hardening

## Goal

Harden the platform's application, tenant, API, deployment, and software-supply-chain boundaries.

## Scope

- Role-based access control
- Tenant isolation validation
- Audit trail
- API authorization tests
- Service-to-service authentication
- Secrets management integration
- Rate limiting
- Security headers
- Dependency vulnerability scanning
- Container image scanning
- SBOM generation
- CI security checks
- Backup/restore validation
- Migration rollback testing
- Least-privilege deployment guidance
- Threat-model documentation

## Exit Criteria

- Security tests are automated
- Tenant-boundary tests exist
- Audit events are queryable
- Supply-chain scanning is part of CI
- Backup/restore procedure is tested
