# v3.18.0 — Performance & Scale Validation

## Goal

Replace vague scalability claims with reproducible measurements.

## Benchmark Dimensions

Machine counts:
- 1
- 100
- 1,000
- 10,000 simulated machines where the environment supports it

Worker counts:
- 1
- 10
- 50
- 100 where practical

Measurements:
- telemetry events/second
- API requests/second
- Kafka throughput
- prediction latency
- end-to-end event latency
- recovery latency
- database contention
- lease contention
- CPU utilization
- memory utilization
- queue lag
- failure/retry rates

## Scope

- Reproducible benchmark harness
- Scenario definitions
- Warm-up policy
- Dataset/simulator versioning
- Machine-readable results
- Benchmark report
- Bottleneck analysis
- Regression thresholds where useful

## Exit Criteria

- Benchmarks are repeatable
- Environment is documented
- Results are committed as evidence
- Claims reference measured results rather than architecture alone
