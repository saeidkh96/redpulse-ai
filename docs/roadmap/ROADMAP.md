# RedPulse AI Roadmap

## Direction after v3.7.1

RedPulse AI has moved beyond broad feature accumulation. From v3.8.0 onward, the roadmap prioritizes production validation, distributed execution, failure engineering, measurable scalability, and deeper predictive-maintenance intelligence.

The guiding principle is:

> Fewer new modules. Deeper implementation. Real failure scenarios. Real distributed execution. Reproducible evidence.

## Release Plan

| Version | Milestone | Primary Goal |
|---|---|---|
| v3.7.1 | Runtime Resilience Validation | Durable replay, leases, heartbeat, ownership fencing |
| v3.8.0 | Production Runtime & Failure Engineering | Real crash recovery and robust failure handling |
| v3.9.0 | Distributed Runtime & Kubernetes | Multi-worker runtime under Kubernetes |
| v3.10.0 | Event-Driven Industrial Platform | Kafka-based telemetry and event architecture |
| v3.11.0 | Large-Scale Fleet Intelligence | Spark-powered historical and fleet analytics |
| v3.12.0 | Production MLOps | Registry, monitoring, orchestration, retraining |
| v3.13.0 | Advanced Failure Intelligence | Stronger predictive-maintenance models and uncertainty |
| v3.14.0 | Agentic Maintenance Intelligence | Evidence-driven maintenance agents with human approval |
| v3.15.0 | Enterprise Automation & Integration | n8n, Power Automate, webhooks, enterprise workflows |
| v3.16.0 | Security & Enterprise Hardening | RBAC, auditability, isolation, supply-chain security |
| v3.17.0 | Observability & SRE Validation | SLI/SLO, tracing, alerting, operational dashboards |
| v3.18.0 | Performance & Scale Validation | Reproducible load, concurrency, and recovery benchmarks |
| v4.0.0 | Production-Grade Industrial AI Platform | Consolidation, evidence, release hardening |

## v4.0 Exit Philosophy

v4.0.0 is intended to close the main feature-expansion phase. After v4.0.0, future work should primarily focus on stabilization, domain validation, real integrations, documented benchmarks, and targeted improvements rather than continuously adding frameworks.
