# v3.17.0 — Observability & SRE Validation

## Goal

Turn observability foundations into measurable operational behavior.

## Scope

- Runtime metrics
- Worker metrics
- Lease takeover metrics
- Retry metrics
- Dead-letter metrics
- Kafka metrics
- Model metrics
- Machine-health metrics
- Structured logs
- Distributed tracing
- Trace correlation
- Prometheus scraping
- Grafana dashboards
- Alert rules
- SLI definitions
- SLO definitions
- Error budgets
- Recovery-time measurement
- Runbooks for selected failure classes

## Candidate Metrics

- redpulse_runtime_retries_total
- redpulse_worker_takeovers_total
- redpulse_lease_expirations_total
- redpulse_dead_letter_executions_total
- redpulse_runtime_recovery_seconds
- redpulse_failure_predictions_total
- redpulse_prediction_latency_seconds
- redpulse_machine_health_score

Names should be finalized to match existing metric conventions.

## Exit Criteria

- Dashboards are backed by real emitted metrics
- Alerts have documented thresholds
- At least one SLO has a measurable SLI
- Recovery scenarios can be traced across services
